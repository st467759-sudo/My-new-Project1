# Task & Expense Tracker — TrackMate

A beginner-friendly web development project made with **HTML, CSS and JavaScript**.

## Features
- Dashboard with task and expense summaries
- Add, complete, filter and delete tasks
- Set task due dates and priorities
- Add and delete expenses with category and date
- Expense totals and category-wise breakdown
- Responsive layout for mobile and desktop
- Saves data in the browser using `localStorage`

## How to run
1. Extract the ZIP file.
2. Open the `index.html` file in Chrome, Edge or another modern browser.
3. Start adding tasks and expenses.

No installation or internet connection is required after the files are extracted. Google Fonts are optional; the app uses fallback fonts if unavailable.

## Technologies
- HTML5 — page structure
- CSS3 — styling and responsive layout
- JavaScript — application logic and local storage

## Project note
This is a front-end academic demonstration project. Data is stored locally in the browser on the device where it is used. It does not include a server, login system or cloud synchronization.
